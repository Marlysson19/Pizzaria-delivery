🍕 Pizzaria Delivery Online

Projeto de um site de Pizzaria Delivery Online, desenvolvido para oferecer aos clientes uma experiência simples, rápida e intuitiva para escolher suas pizzas, montar o pedido e realizar a solicitação de entrega.

📌 Sobre o Projeto

A Pizzaria Delivery Online é uma aplicação web desenvolvida com o objetivo de facilitar o processo de compra de pizzas pela internet.

O cliente pode visualizar o cardápio, escolher uma pizza, selecionar a quantidade, adicionar produtos ao carrinho e finalizar o pedido.

O projeto também foi desenvolvido como forma de praticar e aprimorar conhecimentos em desenvolvimento web, principalmente em HTML, CSS e JavaScript.
